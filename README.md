# fashion-mnist-classification

Проект по классификации изображений одежды с помощью свёрточной нейросети (CNN) на PyTorch.

- Загрузка данных Fashion MNIST.
- Построение модели CNN (2 свёрточных слоя, пулинг, полносвязные слои).
- Обучение модели (5 эпох) и оценка точности.
- Визуализация процесса обучения (графики loss и accuracy).

Используемые технологии
- Python 3
- PyTorch
- Torchvision
- Matplotlib

Запуск
1. Открыть файл `Fashion_MNIST_Classification.ipynb` в Google Colab.
2. Запустить все ячейки по порядку.

Результаты
Test Accuracy: 91.31%
